# Электрички России

Android-приложение на Kotlin для получения расписания пригородных поездов через API Яндекс Расписаний. Интерфейс на русском языке, без Google Play Services.

## Что есть в проекте

- Запрос расписания по станции (`/v3.0/schedule/`).
- Поиск маршрута между станциями (`/v3.0/search/`).
- Поиск станций по названию через официальный список станций (`/v3.0/stations_list/`); найденные станции можно выбрать для отправления и прибытия.
- Выбор даты.
- Сохранение последнего успешного ответа каждого запроса в локальной базе Room; при сетевой ошибке приложение пытается показать кэшированный ответ.
- Настройка API-ключа внутри приложения.
- Локальная работа с избранным в текущей версии не реализована; проект оставлен без фальшивой имитации этой функции.

## Требования

- JDK 17
- Android SDK с платформой Android 35
- Gradle 8.11.1 (рекомендуется для Android Gradle Plugin 8.10.1)
- Android SDK Build Tools

## Настройка API

1. Откройте страницу API Яндекс Расписаний: https://yandex.ru/dev/rasp/raspapi
2. Получите и активируйте ключ в Кабинете разработчика.
3. Установите приложение и в разделе «Настройки API-ключа» вставьте ключ.
4. Введите код станции. Например, в адресе `https://rasp.yandex.ru/station/9600213` код станции для API — `s9600213`.
5. Нажмите «Расписание станции» либо введите второй код и нажмите «Найти маршрут».

Используется актуальный рекомендованный домен `api.rasp.yandex-net.ru`. Условия и доступность API зависят от Яндекса и выбранного ключа.

## Сборка

Установите JDK 17 и Android SDK, затем задайте путь к SDK:

```sh
export ANDROID_HOME="$HOME/Android/Sdk"
export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"
```

В каталоге проекта:

```sh
chmod +x build.sh gradlew
./build.sh
```

Скрипт собирает debug APK. Результат:
`app/build/outputs/apk/debug/Elektrichki-Russia-debug.apk`

Если Gradle не установлен, установите Gradle 8.11.1 или сгенерируйте стандартный Gradle Wrapper:

```sh
gradle wrapper --gradle-version 8.11.1
./build.sh
```

Установка на подключённый телефон:

```sh
adb install -r app/build/outputs/apk/debug/Elektrichki-Russia-debug.apk
```

## Важные ограничения первой версии

- Первый поиск по названию скачивает большой официальный список станций (десятки мегабайт), разбирает его потоково и сохраняет компактный индекс российских станций во внутреннем каталоге приложения (сам JSON удаляется). Последующие поиски быстрые и используют индекс. Чтобы пересоздать индекс, удалите данные приложения.
- Ключ берётся из настроек приложения, а если там пусто — из `api-key.properties` / переменной `YANDEX_RASP_API_KEY`, заданной при сборке.
- Сохранённый результат показывается только при сетевой ошибке; ошибки API (неверный ключ, лимит) показываются как есть.
- API может ограничивать запросы или возвращать ошибки доступа в зависимости от статуса ключа.
- Кэш сохраняет успешные ответы по конкретному запросу и дате; при первом запросе без сети данных в кэше ещё нет.
- Перед распространением проверьте условия использования API и требования к указанию источника данных. В интерфейсе источник обозначен как «Яндекс Расписания».
- APK здесь не собран: для сборки необходимы локальные JDK, Android SDK и доступ к Maven-репозиториям.


## Исправление ошибки KAPT / Kotlin Metadata

В этой версии Room compiler обновлён до 2.7.2, а генерация кода переведена с KAPT на KSP `2.1.20-1.0.32`. Это устраняет типичный конфликт, при котором старый обработчик Room не понимает Kotlin metadata 2.1.0.

Рекомендуется собирать проект Gradle 8.11.1 с JDK 17. Если до этого сборка выполнялась на Gradle 9.8, проверьте версию wrapper/установленного Gradle: Android Gradle Plugin 8.10.1 рассчитан на Gradle 8.11.1.
